## HopOn v2.4.2

月报下钻 + 一批可靠性修复。

### 新增

- **真月报下钻**：报表页「2026-11 本月」徽章可点击，弹出整月月历
  - **热力视图**：颜色深浅 = 当天完成委托的游戏数，悬浮显示当天逐游戏明细
  - **分游戏视图**：选中一款游戏看它的整月历（✓ 完成 / ✗ 未完成 / ⋯ 等待）
  - ‹ › 切换历史月份
- **关机前落盘**：彻底退出 / 系统关机前自动做一轮静默巡检，与凌晨 03:50 的日界前班互补
- **开机自启残留自动清理**：老版本注册的自启键首启自动移除

### 修复

- **守护进程停止旗标竞态**：残留的停止标记不再让后续拉起秒退
- **回满即推预测断链**：预测写入调用契约修复（该功能此前从未真正工作）
- **明日方舟活动名**：预告型公告清洗出干净活动名
- **开机自启开关**：修复展开设置时被误拨；面板重排
- 月报弹窗排版与视图切换确定性

### 安全

- **推送渠道密钥 DPAPI 加密**：SendKey 等与账号凭证同等加密落盘
- 出厂占位符不参与加密（全新安装状态判定更准）
