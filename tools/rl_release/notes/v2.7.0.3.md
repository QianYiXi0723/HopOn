# HopOn v2.7.0.3

## ✅ 这次更新了什么

**自动重启这次真的修好了（上一个版本还没到位）：**

- 更新完成后的自动重启改为**最多 5 轮重试**，任一轮成功才算数；
- **判定标准收紧**：新窗口必须**连续存活 5 秒**才算启动成功——之前只要
  一瞬间活着就报「已启动」，实际它可能马上就退了（这就是「更新完打不开」
  一直没修掉的原因）；
- 更新程序本身也纳入自动更新（以后更新程序的修复也能送到你机器上）；
- 万一 5 轮都没起来，会明确提示你手动双击，不再假装成功。

## ⬇️ 安装

2.7.0 及更新版本点「立即安装」即可全自动；更早版本请到下载目录双击
Setup.exe 完成最后一次手动安装。
