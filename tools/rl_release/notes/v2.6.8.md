# HopOn v2.6.8

## ⚠️ 这是过渡版本

这次装到 2.6.8 仍需你手动点「立即安装」并走完安装程序。
原因：2.6.7 及更早的安装包里安装接口还是占位代码，只有升到 2.6.8 之后
全自动安装才生效——**从下一个版本起，点一下就装完**。

## ✅ 修了什么

**下载完不再让你猜下一步**：以前只显示「校验通过」+ 小字链接，像卡住了。
现在完成态是绿色「✓ 下载并校验完成」+ 蓝色主按钮**「立即安装」**，
下面一行说明「安装程序将打开，按提示完成即可，数据不受影响」。

**装完自动拉起新版**：点「立即安装」→ 应用自动关闭 → 静默安装 →
自动打开新版。过程中有三道保险，任何一步不对都会写日志而非静默失败
（安装器退出码非 0 / 报成功但没装上主程序 / 装好先确认再拉起）。

**首次安装也一次装对**：目录固定标准位置，不会因历史记录装到奇怪地方。

## 🔧 已知限制

- 安装包与已装版本完全相同时，安装程序会跳过写入（内容一致），正常
- 卸载不删账号配置与历史数据，重装后直接可用
- 本版仍需手动完成一次安装（见顶部说明）
