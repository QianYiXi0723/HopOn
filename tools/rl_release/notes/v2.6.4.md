# HopOn v2.6.4

## 🚀 一键安装更新（本版核心）

- 检查更新弹窗的下载校验完成后，**「一键安装更新」点一下**：应用自动关闭 → 静默安装（无窗口）→ **自动重启** → 新版本上线——全程无需找文件夹、无需手动操作
- 两击确认防误触（首击变「再点一次确认」，3 秒超时还原）
- 防降级保护：安装包版本不高于当前版本时拒绝安装

## ⏳ 安装过程可视化

- 静默安装的黑暗期有进度条+阶段文案（连接安装器 → 关闭应用 → 复制文件 → 重启 → 即将完成），不再「窗口消失不知道在干嘛」
- 重启后自动确认结果：「✓ 已成功更新到 vX.Y.Z，欢迎回来」/ 失败时明确提示可重试或手动安装
- 安装日志落地 logs/install.log（静默安装失败时的唯一诊断线索）

## 🔧 发版链自洽体系（v2.6.2 起连续修复的收官）

- SHA256SUMS 按定稿产物生成（v2.6.0/v2.6.1 的错位问题根治）
- 检查更新弹窗：版本号大字锚点+更新公告+双下载渠道（GitHub/Gitee）+站内下载
- 壳外链转系统默认浏览器（修复点渠道按钮没反应）
