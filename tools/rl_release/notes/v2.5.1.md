## HopOn v2.5.1

第一队列六件套：可靠性与提醒主路径大升级。

### 新增

- **数据自愈三件套**：
  - 配置 / 历史 / 活动缓存四大写手全部原子写 + fsync 耐久线（断电不留半截文件）
  - **每日快照轮转**（daily 保留 7 天 + 周日晋升 weekly 保留 4 周）+ 启动校验：
    主数据文件损坏时自动从快照回填并主动告知（Chromium / VS Code 都没做的）
  - explorer 重启后托盘图标自动重挂（TaskbarCreated），状态色不错乱
- **截止梯度提醒**：活动结束推送改三段——**规划（剩 72h）/ 行动（剩 24h）/ 冲刺（剩 6h）**，
  每段独立可设、填 -1 关闭该段、每档只推一次、错过的档下次巡检补发；
  活动卡片显示段位标记与已推打勾；取代旧「每天重复提醒」单档
- **托盘升级**：右键菜单直显各游戏体力与预计回满（一字简称定宽排版，整齐不乱）；
  **待办在标题里点名**（不开控制台就知道要做什么）；有待办时图标琥珀角标
- **诊断包一键导出**：控制台按钮 + 托盘菜单——脱敏配置 + 近 7 天日志 + 环境信息打包到桌面，
  三道安全闸（真实密钥值扫描命中即中止），给开发者反馈问题从「发文件夹」变「发一个 zip」
- **杀软拦截自检**：定时页新增自检抽屉——判「是不是被杀软办了」（文件消失 / Defender 记录 / 心跳三信号），
  附 Windows Defender / 火绒 / 360 加白名单步骤、本机 SHA256 对照官方发布、误报上报入口
- **第二实例不再静默退**：重复启动自动唤起控制台

### 修复 / 改进

- 绑定开关气泡改念真实昵称 + 角色 ID（不再念占位名）
- 体力已满推送只说「已满 N/N」，去掉说教后半句
- 日常做完后进度条变绿
- 体力阈值卡顺序与游戏概览一致（米哈游 → 鹰角 → 库街区）

### 下载

- **安装版** `HopOn_v2.5.1_Setup.exe`：双击安装，装到用户目录，**卸载不删配置与数据**。
- **绿色版** `HopOn_v2.5.1_Windows_x64.zip`：解压即用，不需要装 Python。
- `SHA256SUMS.txt`：下载后可用它核对文件完整性。

> 从旧版本覆盖安装即可，登录凭证与历史记录都会保留。
