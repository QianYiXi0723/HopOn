# HopOn v2.7.0

## ✅ 这次更新了什么

**更新体验全面重构**（学习 Chrome / VS Code / Firefox 的更新方式）：

- 下载完成的那一刻，新版本就已经在后台准备就绪；
- 点「立即安装」→ 应用关闭 → 几秒后新版自动回来，全程无需任何手动操作；
- 安装过程任何一步失败，都会自动恢复到旧版本，绝不留半残状态；
- 安装期间连接提示改为安静的横幅，不再红字轰炸。

**说明**：2.6.10.12 及更新版本点「立即安装」即可全自动完成本次升级；
更早的版本请到下载目录双击 Setup.exe 装一次（这是最后一次手动安装，
之后就永久全自动了）。

## ⬇️ 安装

双击 Setup.exe（首次安装），或按上面的说明在应用内一键更新。
