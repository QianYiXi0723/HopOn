# HopOn v2.6.0

自定义提醒 + 日常概览卡片化——HopOn 从「游戏数据」走向「你的日常」的第一步。

### 新增：自定义提醒

- **无 API 游戏也能上了**：宿舍电费、课程表、健身打卡——凡是游戏外数据源查不到的日常，
  在这手动记一条，每天定时提醒，做完勾掉，次日按各自重置时刻自动重开
- **消息模板逐项自定义**：支持 {name}/{time} 变量、实时预览、恢复默认文案
- **双推送模式逐项可选**：随巡检推送（并进班次推送末尾，不单独打扰）/ 独立时刻推送（只早不迟，迟过当场补发）
- **逐项重置时刻**：默认 04:00 随游戏日常重置，可逐项改（健身房设 00:00 也行）
- **启用/停用开关**：暂停提醒不用删，配置保留一键恢复

### 新增：日常概览卡片化

- 手动打卡项以**与游戏卡同构的卡片**呈现在日常概览中（首字方框图标+连续天数真算+整卡点击打卡）
- 卡头**可见「打卡/✓已打卡」按钮**——状态一眼可见，不用猜哪里能点
- 概览更名「游戏概览」→「日常概览」，游戏与手动项一屏同览

### 新增：托盘升级

- 右键菜单直显各游戏体力与回满倒计时（一字简称定宽排版）
- **待办在标题点名**：「2 项待办：火影忍者 未清 · 绝 已满」——不开控制台就知道要做什么
- 有待办时图标琥珀角标；手动打卡项在托盘直接勾选

### 新增：可靠性与体验

- **守护进程启动/停止合一为拨杆开关**，操作中防误翻
- **运行日志底栏 + 托盘 + 杀软自检抽屉**三处一键导出脱敏诊断包（真实密钥扫描 fail-closed）
- **监控开关切换后自动刷新缓存**——托盘/概览/实时体力跟随开关走，不再出现"勾了游戏托盘没有"
- 杀软拦截自检改状态驱动渲染：健康=一行绿字，步骤指引只在异常时出现
- 托盘按启用账号集过滤，停用游戏不再泄漏；启用未查询的游戏显示「待巡检」占位

### 下载
