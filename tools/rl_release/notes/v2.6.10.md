# HopOn v2.6.10

## ✅ 这次更新了什么

**绑定完马上知道行不行**：扫码或粘贴 Token 绑定成功后，软件当场试查
一次——成功给绿色确认，失败直接告诉你原因，不用等到明天才发现绑坏了。

**半夜不再被吵醒**：免打扰时段现在也管住周报和你自设的打卡提醒。
到点先不打扰，出了免打扰时段自动补上，一条不丢。

**推送更可靠**：手机推送真失败了会自动重试补发；只用页面通知的用户
不会再被同一条消息反复轰炸。

**细节**：手动打卡提醒推送成功后不再重复弹。

## ⬇️ 安装

2.6.9 用户点「立即安装」即可全自动；2.6.8 及更早仍需手动装一次
（完全退出 HopOn 后运行下载目录里的 Setup.exe）。
