# HopOn v2.7.0.6

## ✅ 这次更新了什么

**更新成功后能正确看到「已成功更新」提示（之前这条会被吞掉）：**

- 更新完毕重新打开时，若引擎还没起来，之前的代码会把「更新中」标记
  提前清掉——导致你永远看不到成功提示，也不知道到底装没装上。
  现在会等拿到版本号、确认后才提示。
- 安装过程中的失败不再误清标记：包已经下好时（绝大多数情况），
  重启后仍会自动接着装完。
- 安装进度提示从 20 秒拉长到 90 秒——之前 20 秒就暗示「可能失败了」，
  但实际换文件 + 重启可能需要更久，容易让人以为出错去手动开第二个窗口。

## ⬇️ 安装

2.7.0 及更新版本点「下载并安装更新」即可全自动；更早版本请到下载目录
双击 Setup.exe 完成最后一次手动安装。
