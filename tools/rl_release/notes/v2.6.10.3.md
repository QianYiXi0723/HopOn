# HopOn v2.6.10.3

## ✅ 这次更新了什么

**更新完不用再手动开**：装完软件会自己重新打开，不用你去任务管理器
结束进程，也不会一直弹「无法连接本地」。

**加载那几秒不再乱弹窗**：刚启动、正在安装或退出时，页面一时连不上
本地服务属于正常现象，现在会安静等它准备好，不再红字刷屏；真连不上
才会提醒你。

**装完自动回来，双保险**：以前全靠一个组件拉起，被安全软件拦住就没人
管了；现在安装完自己也会打开，两个一起保证。

## ⬇️ 安装

2.6.10 及更新版本点「立即安装」即可全自动；更早版本仍需手动装一次
（完全退出 HopOn 后运行下载目录里的 Setup.exe）。
