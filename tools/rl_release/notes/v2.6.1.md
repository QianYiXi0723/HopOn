## HopOn v2.6.1

v2.6.0 之后的收尾更新：交流群入口、守护进程拨杆、失败语义修正与细节打磨。

### 新增 / 改进

- **官方交流群**：侧栏底部与 README 加入 QQ 群 **1135683779**，点击一键复制群号（以 Releases 页公布为准，谨防冒名）
- **守护进程拨杆开关**：启动/停止双钮合一为拨杆（开=运行中，关=停止），操作中防 3 秒轮询误翻杆
- **运行日志底栏「导出诊断包」**：日志的自然位置一键直达；守护进程卡重复按钮已移除
- **失败语义修正**：本地服务不通（换装/引擎重启空窗）显示「本地服务未就绪，正在自动重连…」并每 4 秒自动重试；「游戏查询失败」只用于真正的查询错误——不再把服务空窗误报成查询失败

### 修复

- 清理已删按钮的悬空 JS 绑定（否则刷新时整页脚本报错）
- 手动打卡卡去掉伪进度条：二值状态只由「打卡 / ✓ 已打卡」按钮与颜色表达
- 抽屉行首勾选框改职为「启用/停用」：暂停提醒不用删配置，今日完成收敛到概览卡与托盘
- 活动结束提醒输入框补前缀标签与单位（提前/天、规划/行动/冲刺/时）
- 概览卡全量露出：移除卡内滚动，页面级滚动接管；单游戏时不再霸占整行（auto-fill）
- 监控开关切换后自动刷新实时缓存，托盘/概览/实时体力跟随开关走
- 托盘按启用账号集过滤，停用游戏不再泄漏；启用未查询的游戏显示「待巡检」占位

### 下载

- **安装版** `HopOn_v2.6.1_Setup.exe`：双击安装，装到用户目录，**卸载不删配置与数据**。
- **绿色版** `HopOn_v2.6.1_Windows_x64.zip`：解压即用，不需要装 Python。
- `SHA256SUMS.txt`：下载后可用它核对文件完整性。

> 从旧版本覆盖安装即可，登录凭证与历史记录都会保留。
