# HopOn v2.7.1

## ✓ 这次更新了什么

这一版主要收拾界面细节，顺手修了一个会误导人的问题：

- **活动日历**：任务做完但还没结束的活动不再被收进折叠区，直接显示在列表里；
- **卡片外观**：左侧色条不再顶出卡片圆角；悬停描边不再被色条盖住；
- **每月报表**：单游戏视图去掉多余悬停提示；总表悬停只留「完成 x/x」和「长按补录」；
- **七日报表**：格子调高，看着更舒展；
- **实时体力**：卡片补上悬停效果，和日常概览一致；
- **通知绑定**：最大化窗口下两渠道并排，入口各贴在对应输入框上方；
- **守护进程**：状态条间距加大，不再挤在一起；
- **设置页**：休眠提醒、杀软自检、自定义提醒、免打扰都补了说明，问号也不再贴着标题；
- **修复**：杀软自检曾把正常安装目录误判成「疑似被拦截」，不会再误报。

**手机端**：游戏卡加上对应图标，状态单独显示在卡片右上角。

## 安装
2.7.0 及更新版本点「立即安装」即可自动完成；更早版本请先完全退出 HopOn，再运行下载目录里的 Setup.exe 完成一次手动安装。
