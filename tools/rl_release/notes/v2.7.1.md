# HopOn v2.7.1

## ✓ 这次更新了什么

界面这一版改动比较多，主要围绕「看起来更整洁、操作更顺手」：

- 活动日历：任务做完但还没结束的活动不再被收进折叠区，直接显示在列表里；
- 活动卡和游戏卡的左侧色条改了收尾方式，不再顶出卡片的圆角；
- 卡片悬停时的描边不会再被左侧色条盖住；
- 每月报表：单游戏视图去掉了多余的悬停提示；总表悬停只显示「完成 x/x」和「长按补录」，不再堆一长串明细；
- 七日报表的格子调高了一些，看着更舒展；
- 实时体力的卡片也加上了悬停效果，和日常概览一致；
- 通知绑定在最大化窗口下两个渠道并排显示，各自的入口贴在对应输入框上方；
- 守护进程状态条间距加大，不再挤在一起；
- 设置页的休眠提醒、杀软拦截自检、自定义提醒、免打扰时段都补了说明，问号与标题的间距也调开了。

另外修复了一个会误导人的问题：

- 杀软拦截自检曾把正常的安装目录误判成「疑似被拦截」，现在不会再误报。

## 手机端

- 游戏卡加上了对应的游戏图标，状态单独显示在卡片右上角。

## 安装
2.7.0 及更新版本点「立即安装」即可自动完成；更早版本请先完全退出 HopOn，再运行下载目录里的 Setup.exe 完成一次手动安装。
