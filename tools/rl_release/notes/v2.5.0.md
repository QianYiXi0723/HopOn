# HopOn v2.5.0

## 🎮 八款游戏

新增三款游戏的完整接入（查询/日常判定/体力/活动/推送全链路）：

- **崩坏3**（米游社）：体力（支持道具破上限 480/240 三态）+ 每日训练判定
- **鸣潮**（库街区）：结晶波片 + 结晶单质溢出显示 + 每日活跃判定 + 活动日历
- **战双帕弥什**（库街区，与鸣潮同一张 token）：血清 + 每日活跃 + 活动日历

## 🖥️ 界面职责分离

- **实时体力** = 纯体力视图：数值/进度条/预计回满，不再混杂日常状态
- **游戏概览** = 日常进度：每任务一行进度条（与体力条同形态），体力条删除
- 游戏排序三页统一（平台分组序），小窗下概览/实时均为两列排布

## 📅 活动日历形态

- 英雄卡 2x2 通栏置顶（最紧急且有内容的活动）
- 普通卡统一 180px 等高，压缩排版
- 同截止合并卡：紧凑化 + 光标悬浮看成员 + 成员分别删除 + 整组删除
- 不同游戏同截止的活动也会自动合并（成员带游戏名前缀）
- 月报热力图色阶 8 档自适应（随监控游戏数量伸缩）

## 🔔 提醒与调度

- 定时提醒**只早不迟**：到点窗口 [目标-30s, 目标]，迟过目标走补发
- 体力满格文案修正（已满 ≠ 即将溢出）
- 崩3/鸣潮/战双的凭证失效告警、检查失败隔离全部就位

## 🔧 稳定性

- 角色列表接口改用 account_id（部分账号 ltuid 失效问题）
- 库街区瞬时 220 防抖重试、roleName 脏值防护
- 壳版本号与引擎版本号一致性门禁
- 「设备信息.apk」公开直链获取（扫码不通时的兜底）
