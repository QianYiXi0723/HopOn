# HopOn v2.7.0.2

## ✅ 这次更新了什么

**修好「更新完成后应用打不开 / 提示无法连接本地」——这次找到了真根因：**

- 更新程序替换完文件后拉起新版时，新版可能被旧版还没释放的单实例锁顶回去，
  而它退出时不写任何日志（退出码 0），所以一直查不出来。
- 现在：新版会等旧版真正退出后再接管（最多等 60 秒），**任何放弃都会写进日志**；
  更新程序也会确认新版真的启动了，失败不再假报「已启动」。
- 同时修掉两个隐藏问题：更新程序可能被旧版进程一起带走（Job 对象脱离写错）、
  以及更新日志在关键阶段被丢弃。

## ⬇️ 安装

2.7.0 及更新版本点「立即安装」即可全自动；更早版本请到下载目录双击
Setup.exe 完成最后一次手动安装。
