# HopOn v2.6.5

## 🚀 一键安装更新（本版核心，v2.6.4 只带了下载）

- 检查更新弹窗改**单一主按钮贯穿全流程**：「下载并安装更新」点一下 = 下载 → SHA-256 校验 → 静默安装 → 自动重启 → 新版本上线，全程无需任何手动操作
- 安装完成自动确认：「✓ 已成功更新到 vX.Y.Z，欢迎回来」；未成功则明确提示可重试或手动安装
- 防降级保护：安装包版本不高于当前版本时拒绝安装

## 🖥 更新弹窗视觉全面重构（学 BGI 18k★ 更新系统）

- 版本号独立大字锚点行（22px），公告首行去重不与标题重复
- 下载渠道改 **BGI 式卡片**：GitHub（国际）/ Gitee（国内）纵排双卡，图标全 SVG 矢量化（新增 i-download/i-globe/i-branch 三个图标，emoji 清零），副行三级文字色清晰可读
- 渠道排序与命名对齐 BGI：开源渠道优先、场景描述（需网络环境/免梯直连），去「主渠道」生硬措辞
- **修复安装遮罩「一旦显示永远关不掉」**（inline display:flex 压 [hidden]——黑遮罩盖住整个控制台的根因）

## 🔧 稳定性

- **站内下载终态持久化**：下载完成的安装包状态落盘，重启引擎/壳后不再「检测不到本地资源」
- **一键安装根治「锁赛跑」**：引擎自杀清锁 → 独立桥接进程跑安装器 → 装完拉壳拉全家（第一版安装器与引擎退出赛跑，engine 文件被静默跳过的半残更新已根治）
