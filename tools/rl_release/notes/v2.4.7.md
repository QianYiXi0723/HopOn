## HopOn v2.4.7

体力显示三态真实值 + 星铁备用开拓力。

### 新增 / 修复

- **体力三态全用真实值**：未满 `157/200`、满 `200/200`、**道具突破上限 `312/240` 原样显示**——
  悬浮提示区分「体力已满」与「超出上限 N（道具/效果临时提升）」
- **星铁备用开拓力**：补抓 `current_reserve_stamina`（此前漏抓，接口有此数据），
  进度串显示「205/300 + 备用 298」；备用满时计入满员判定
- **推送预警措辞**：超出上限时「已超出上限 312/240（超出 72 点）！」，
  达到阈值仍为「即将溢出」
- 修一个内部回归：备用串加入后星铁的溢出预警解析失效

### 各游戏体力口径说明

- **原神 / 明日方舟 / 终末地**：无溢出机制，满即停，数字准确
- **崩坏：星穹铁道**：主体力 + 备用开拓力都显示
- **绝区零**：备用电量（溢出转存槽）官方接口不提供，只显示主线电量——溢出部分请进游戏查看
